# Contributing

Contributions should improve reproducibility, defensive value, or evidence quality.

1. Work only with local fixtures or systems you own or are authorized to test.
2. Add or update tests for code changes.
3. Cite authoritative sources for factual security claims.
4. Keep generated worksheets marked **Planned** until a person completes and documents the work.
5. Do not submit secrets, personal data, live target data, weaponized payloads, fabricated findings, or claims unsupported by saved evidence.
6. Run `python -m pytest` before opening a pull request.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
