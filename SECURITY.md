# Security Policy

## Reporting a repository vulnerability

Please use GitHub private vulnerability reporting when available. Otherwise contact Rohit Dixit through [rohitdixit.dev](https://rohitdixit.dev) without including sensitive exploit details in a public issue.

Include the affected path and revision, impact, safe reproduction steps, and suggested remediation. Reports about third-party products should be sent to their maintainers through the applicable disclosure process.

This project is a defensive lab. Do not test techniques against systems without explicit authorization.
